#### **2. 趋势判定与趋势韧性评估（多周期锚定与共振验证）**
- **首要步骤**：同时评估**周线、日线**的主要趋势。
  - **共振**：周期方向一致，趋势确定性最高。
  - **矛盾**：以更大周期（周线）趋势为背景，将日线走势定性为“回调”或“反弹”。
- **【趋势韧性量化评估】**：
  - 计算股价与关键趋势生命线（如20日均线、60日均线）的**乖离率（BIAS）**。
    - 乖离率 < 8%：正常强势区，可正常建仓。
    - 乖离率 8% ~ 15%：加速期，**允许追高但仓位减半**（例如右侧仓位从15%降至7.5%），止损位上移至5日均线。
    - 乖离率 > 15%：超买区，**禁止开新仓**，仅可持有或减仓。
    - **趋势强度修正**：若股价连续3日站稳5日均线且MACD红柱持续放大，即使乖离率偏高（8%~15%），也可视为强势延续，允许小仓位参与。
  - 在主升浪中，将日线级别的回调**首先定性为“趋势内的波动”而非“趋势反转的开始”**，除非放量跌破关键趋势生命线。
- **板块协同**：若板块整体处于主升浪，龙头个股的单独巨震更倾向定性为洗盘。
- **【板块地位权重】**：
  - **龙头股特权**：若目标股是板块情绪龙头或市值中军，对其量价背离容忍度提高：首次放量断板/长上影，只要收盘未破5日线且板块梯队完好（板块内仍有3只以上个股涨幅>5%），自动进入观察期而非卖出。
  - **跟风股限制**：若目标股是跟风股，必须要求其走势强于板块指数（相对强度>1），否则一票否决。
  - **板块共振加分**：若个股所属板块当日涨幅排名全市场前5，且板块内有3只以上个股涨幅>5%，则个股的突破信号可信度大增，可适当放宽其他条件（如允许单日突破、量能要求降至1.1倍）。

- **左侧潜伏机会**：

#### **6. T+1应对与防守反击（执行预案）**

  - 操作：不立即清仓，进入**2-3个交易日观察期**。**期间强制将仓位降至原计划的一半**（例如从总仓20%降至10%）。
  - 明确标准：
    - **收复标准**：在观察期内，股价需重新站稳短期压力位（如5日均线），且量能配合，则买回仓位。
    - **证伪标准**：若观察期内股价**放量跌破关键趋势生命线**（如20日均线），则清仓剩余部分。
  - 目的：过滤主升浪中的剧烈洗盘，给市场时间证明信号的真伪，同时避免在不确定性中承受过大的仓位压力。
- **【时间过滤（原时间止损）】**：左侧潜伏后，**3-5个交易日**未脱离成本区或未见异动，但股价仍维持在买入价附近且未破位，若买入逻辑未变（如催化剂仍在、趋势未坏），可放宽观察至**8-10个交易日**，但需重新评估逻辑。若逻辑弱化则主动减仓。
